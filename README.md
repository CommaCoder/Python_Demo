# Python Demo - TodoList CLI

一个基于 Python 开发的命令行 TodoList 任务管理工具。

这是我的第一个完整 Python 工程化项目，主要用于学习 Python 项目结构、模块化开发、Git版本管理、数据持久化以及单元测试等软件开发基础流程。

---

## 📌 项目介绍

TodoList CLI 是一个运行在终端中的任务管理程序。

用户可以通过命令行菜单完成：

- 添加任务
- 查看任务列表
- 修改任务
- 删除任务
- 保存任务数据
- 重启程序恢复任务


项目从简单 Python 脚本逐步重构为具有基本工程结构的小型项目。

---

## ✨ 项目功能

### 任务管理

✅ 添加任务

- 支持连续添加任务
- 自动过滤空任务


✅ 查看任务

- 显示当前所有任务
- 自动生成任务编号


✅ 修改任务

- 根据任务编号修改内容
- 支持错误输入处理


✅ 删除任务

- 根据编号删除任务
- 支持非法编号检测


### 数据持久化

使用 JSON 文件保存任务数据：tasks.json
程序启动时自动读取数据。

程序退出时自动保存数据。

解决了关闭程序后数据丢失的问题。
